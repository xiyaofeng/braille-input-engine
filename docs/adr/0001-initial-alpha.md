# ADR-0001: Initial alpha delivery surface

Status: accepted by the project decisions in `SPECIFICATION.md` §27.1.

The alpha uses a TypeScript headless core, ESM/CommonJS/browser-IIFE build outputs, an explicit browser-only surface, no runtime dependencies, a private package manifest, and GitHub-source/optional-release distribution. It keeps automatic browser and real-device evidence separate from M4 human validation.
